# JavaScript 실행 환경 검증

- 검증일: 2026-09-27
- 범위: 첫 JavaScript 실행 계층 및 최소 경기. 전체 서비스 완료를 의미하지 않는다.
- 환경: Windows / Node.js 18.20.2 / quickjs-emscripten 0.32.0 / acorn 8.18.0.

## 선택

Node.js의 별도 자식 프로세스 안에서 WebAssembly로 빌드된 QuickJS를 실행한다. 경기 참가자마다 runtime/context/Player 인스턴스 한 개를 보관하고 각 호출마다 interrupt deadline을 갱신한다. 종료는 경기 종료 시에만 수행한다.

Node의 vm은 [공식 문서](https://nodejs.org/api/vm.html)에서 보안 격리 수단이 아님을 명시한다. 이번 구현은 Node 객체를 직접 전달하는 vm 대신 별도 QuickJS 실행 환경을 채택했다. [QuickJS 바인딩 문서](https://github.com/justjake/quickjs-emscripten)는 interrupt handler, 메모리 제한, 컨텍스트와 핸들 수명을 설명한다.

사용자 코드는 외부에서 고정한 module/exports를 통해 로딩하며, 호스트의 실행 제어부를 어휘적 스코프로 참조하지 않는다. 전달하는 호스트 기능은 제한된 문자열 디버그 출력뿐이다. 파일·네트워크·프로세스 객체를 제공하지 않는다.

## 실제 확인 결과

`npm run verify:runtime` 관측 예:

| 호출 | 결과 | 실행 시간 | 프로세스 |
| --- | --- | --- | --- |
| 1 | 정상, 0 반환 | 0.036ms | PID 16804 |
| 2 | 무한 루프 중단, -1 패널티 | 500.163ms | PID 16804 |
| 3 | 이전 호출에서 저장한 값 3 반환 | 0.039ms | PID 16804 |

PID는 실행마다 달라지며 위 값은 한 검증 실행의 관측 기록이다. timeout 전에 기록된 필드와 호출 횟수가 유지되므로 종료·재시작으로 대체한 결과가 아니다.

자동 테스트로 확인한 항목:

- try/catch/finally 안의 무한 루프 중단 및 다음 호출 회복
- 정규식 built-in의 긴 연산 중단 및 다음 호출 회복
- 32 MiB guest 메모리 제한에 따른 할당 실패 후 동일 인스턴스 호출
- 4개 서로 다른 PID에서 병행 실행, 정상 플레이어가 느린 플레이어보다 먼저 완료
- 같은 플레이어 호출 비중첩
- 30개 출력 제한, 입력 맵 사본, 아이템 인자 전달
- async/import/static 코드 거부
- 호스트 API와 동적 코드 생성 경로 미노출
- 예외 객체의 악성 message getter를 실행하지 않는 오류 처리
- 명시적 경기 종료 전 프로세스 유지, 종료 후 연결 정리

## 시간과 상태에 대한 해석

- 500ms는 guest 함수를 실행하는 구간의 제한이다. 브라우저 통신과 자식 프로세스 요청 대기, 게임 액션 시간은 포함하지 않는다.
- interrupt handler가 제한 경과를 감지하면 현재 호출만 중단한다.
- 물리적으로 정확히 500.000ms에 중단되는 실시간 보장은 아니다. 위와 같이 감지·스케줄링 오차가 있으며 실제 경과 시간을 출력한다.
- 중단 이전 필드 변경은 유지한다. 트랜잭션 롤백은 구현하지 않는다.
- 스레드/프로세스 재시작이나 Promise.race로 결과만 버리는 방식을 사용하지 않는다.

## 기술·운영 한계

- 32 MiB는 QuickJS guest heap 제한이며 전체 OS 프로세스 메모리 한도가 아니다.
- 모든 built-in과 자원 고갈 경로를 포괄적으로 증명한 것은 아니다. 사내 배포 전에 목표 OS·지원 Node 버전·부하에서 검증을 확대한다.
- 프로세스 자체 장애는 시간 초과와 구분하여 현재 개발 버전에서 해당 경기를 종료한다. 자동 재시작하지 않는다.
- 시작 전 로딩·초기화·이름 조회에도 각각 500ms 보호를 적용한다. 시작 준비 정책 값은 후속 운영 명세에서 조정 가능하다.
- 게임 서버는 로컬 바인딩으로 제한했다. 인증·운영 격리·AI 중계·사내 배포는 아직 완료되지 않았다.

```sh
npm run test:browser
```
