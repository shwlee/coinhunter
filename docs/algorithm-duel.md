# 이전 경기 알고리즘과 대결

로그인 사용자는 게임 플레이의 **이전 경기 알고리즘과 1:1 대결**을 선택할 수 있다. 본인의 완료 경기 기록에서 한 경기를 고르면, 그 경기를 실행할 당시의 알고리즘 코드 사본이 현재 선택한 코드의 상대가 된다. 현재 코드는 파일 업로드 또는 본인 저장 코드 중 하나를 사용할 수 있다. 게스트에게는 대결 옵션과 기록 목록을 제공하지 않는다.

경기가 종료되면 로그인한 사용자의 당시 코드 사본, 경기 날짜, 맵, 알고리즘 이름, 캐릭터, 점수, 종료 사유를 계정 저장소에 기록한다. 테스트 플레이도 실제 실행 경기이므로 기록된다. 저장된 알고리즘을 나중에 수정하거나 삭제해도 과거 경기의 코드 사본은 변하지 않는다. 과거에 기록하지 않았던 경기로 소급해 상대를 만들 수 없다.

`GET /api/history`는 본인 기록의 메타데이터만 반환한다. 코드 원문과 소유자 식별자는 목록에 포함하지 않는다. `POST /api/matches`에서 `mode: "duel"`, `opponentHistoryId`, `dummyCount: 0`을 전달한다. 서버는 로그인 계정의 해당 기록을 확인하고 당시 코드 사본을 로드한다. 상대 코드를 요청 본문에서 직접 전달하거나 다른 계정의 기록을 선택할 수 없다. 일반 `practice` 모드는 이전과 같다.

두 알고리즘은 별도 지속 프로세스에서 실행한다. 현재 코드는 선택한 시작 위치, 상대 코드는 대각선 모서리에서 출발한다. 이전 코드는 코비 더미가 아니라 플레이 가능한 다른 캐릭터를 사용한다. 순위, 포디엄, 결과 분석에는 현재/이전 구분을 표시한다.

현재 메타데이터 저장소는 단일 로컬 서버의 JSON 파일이며 당시 코드는 별도 `.js` 파일이다. 기록 보존·삭제 정책과 운영 DB 이전은 배포 단계에서 정한다. 기록 목록에는 코드 원문이나 파일 참조를 노출하지 않는다. 메타데이터와 코드 파일을 함께 백업해야 과거 경기 대결을 복원할 수 있다.
