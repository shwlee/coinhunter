# 이전 알고리즘 대결

파일 선택 단계에서 **이전 알고리즘과 1:1 대결**을 선택하고 현재 코드와 이전 코드의 `.js` 파일을 각각 업로드한다. 각 파일은 최대 64 KiB이며 기존 동기 JavaScript 작성 규칙을 적용한다. 이후 맵, 기믹, 캐릭터, 시작 위치를 선택한다.

대결에는 더미가 참가하지 않는다. 현재 코드는 선택한 위치에서, 이전 코드는 대각선 모서리에서 출발한다. 이전 코드에는 현재 캐릭터와 다른 플레이 가능한 캐릭터를 자동 배정한다. 순위, 포디엄, 결과 분석의 이름 앞에 현재/이전을 표시한다. 두 코드는 별도 지속 프로세스로 실행하며 각 호출에 기존 500ms 제한을 적용한다.

게스트는 로컬 파일만 업로드한다. 파일 내용은 페이지 메모리에 유지되어 다시 플레이할 때 재사용되지만 새로고침 후에는 다시 업로드해야 한다. 코드 보관, 버전 히스토리, 다른 사용자 코드 공개 기능은 추가하지 않는다. 향후 로그인 사용자의 저장된 알고리즘 선택을 같은 대결 참가 입력으로 연결할 수 있다.

API: `POST /api/matches`의 `mode`는 `practice`(생략 시 기본값) 또는 `duel`이다. `duel`에서는 `source`, `opponentSource`, `dummyCount: 0`을 전달한다. 두 코드를 각각 검증하며 경기 스냅샷에는 소스를 포함하지 않는다. 플레이어 `role`은 `current`, `previous`, `dummy` 중 하나이다.

한 경기에서 같은 맵과 기믹 설정을 공유하지만 실시간 계산 시간과 무작위 아이템 배치의 영향을 받는다. 결과는 해당 경기의 비교이며 알고리즘 성능의 확정적 판정은 아니다. 반복 대결, 시드 고정, 위치 교환 자동 경기는 후속 범위이다.
