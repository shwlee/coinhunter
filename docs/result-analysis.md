# 경기 결과 분석

게임 오버 3초 후 포디엄의 ‘결과 분석’ 버튼으로 비교 표를 연다. ‘포디엄 보기’로 돌아오거나 바로 다시 플레이할 수 있다. 고정된 게임판 안에서 분석 표만 스크롤한다. 순위순으로 표시하고 본인 열을 강조한다.

통계는 서버의 `players[].stats`에 경기 동안 누적된다. 최근 40개 디버그 로그와 무관하게 전체 경기를 집계하며 스냅샷으로 전달한다.

- 코인: 실제 획득한 점수별 개수. x2도 개수는 1개이며 추가 점수는 `bonusScore`로 분리한다. 기본 코인 점수 합계 + 보너스 = 최종 점수다. Hurry Up 자동 소멸은 획득으로 세지 않는다.
- 액션: 완료된 턴, 일반 이동, 벽·맵 경계 충돌, 제자리 패널티, 실제 파괴한 벽, 점프 성공·실패. 중도 종료로 취소된 액션은 제외한다. 알고리즘의 -1과 실행 오류로 인한 제자리는 패널티다.
- 계산: 결과를 받은 알고리즘 호출 수, 평균·최대 실행 시간, 시간 초과·예외·잘못된 반환값 횟수. 시간 초과 및 오류 시간도 평균에 포함한다. 랜덤점프와 종료 시 미완료 호출은 제외한다. 계산 완료 후 액션 중 종료되면 계산 통계에만 포함될 수 있다.
- 아이템: 종류별 획득 횟수와 사용량. 신발은 적용된 완료 액션 수(제자리 포함), 망치는 실제 벽 파괴 수, x2는 배율 적용 코인 수, 점프는 완료된 시도 수(실패 포함)다. 획득한 턴에는 이전 아이템 효과로 집계한다.

통계는 현재 경기와 동일한 서버 메모리 생명주기를 따른다. 영구 보관·이전 경기 비교·승패 원인 자동 진단은 이번 구현에 포함하지 않는다. 통계가 없는 예전 스냅샷은 0으로 오인하지 않도록 ‘—’로 표시한다.
