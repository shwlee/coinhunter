# C# 실제 게임 장시간·장애 검증

## 검증 범위

2026-11-20 Windows x64 로컬 환경에서 실제 Node 게임 엔진과 지속 C# 실행기를 검증한다. [자동화 사용법](csharp-endurance-automation.md)에 따라 반복 시작/종료, 엔진 강제 종료, 실행기 강제 종료, 장애 후 새 게임과 30분 동시 게임을 수행한다.

**통과.** 실제 동시 실행 1,803.986초(30분 3.986초), 전체 시험 1,859.233초를 완료했다. 최종 `report.json`의 `passed/qualifiedLongRun`과 `supervisor.json`의 `passed`가 모두 true다. 실제 측정 시각은 2026-11-20 17:48~18:18 KST다.

실행 폴더는 `artifacts/csharp-endurance-f92921bf-5170-4886-91a2-23f8c6708cdf`다. 원본 로그/샘플/receipt는 이 무시된 폴더에 보존하고, 저장소에는 [집계 증거 JSON](benchmarks/csharp-endurance-2026-11-20.json)을 보관한다. 기준 제품 코드는 `1acb520`이며 이번 자동화와 내부 읽기 전용 진단 속성은 측정 당시 미커밋이다.

## 시험 조건

- 동시 게임 2개, 게임당 C# 2명과 JavaScript 1명. 모든 참여자가 진행하기 시작한 시점부터 1,800초 이상 측정한다.
- 맵 40×30, 액션 50ms. 중앙 코인 4개를 두고 알고리즘은 제자리로 반환해 시간/코인 소진에 의한 조기 종료를 피한다. 일반 이동·벽·아이템 게임성 검사는 별도 기존 회귀의 범위다.
- C#마다 128MiB 상태를 유지하고 정상 호출마다 64KiB 배열을 할당한다. 주기적인 무한 루프 timeout과 잘못된 방향 반환으로 동일 객체의 필드 진행을 확인한다.
- GC 구간과 진입 복구는 시험에서만 활성화한다. 게임당 예약 2,304MiB, CPU 상한 100%, 기본 샘플 간격 5초다. 이 조건은 배포 권장 사양이 아니다.
- 시작/종료 3회와 두 종류의 강제 종료를 별도로 수행한다. 강제 종료 대상은 이번 검증이 생성한 PID/시작 시각으로 식별한다.
- 전체 JSONL은 종료 후 스트리밍으로 검사하며 순서·호출/인스턴스 식별자·필드 상태·GC 관측·최종 결과/receipt를 대조한다.

## 메모리·프로세스 관측

- 게임별 전체 OS 그룹의 private commit 최대 관측은 약 1,217MiB / 1,317MiB다. JavaScript 자식 프로세스도 포함하며 게임별 2,304MiB 한도 이내다.
- 별도 PID 샘플의 엔진+C# private bytes 최대치는 약 1,170MiB / 1,265MiB다. 이 합계에는 JavaScript 자식이 빠지므로 전체 게임 메모리로 표시하지 않는다.
- 시작 시점보다 마지막 샘플의 private commit이 높았다. GC/런타임 메모리 변동을 포함하므로 이 한 번의 시험으로 무제한 장기 실행의 메모리 안정성이나 누수 부재를 증명하지 않는다.
- 실행 중 C# 호스트는 4개, 예약 메모리는 4,608MiB로 유지됐다. 종료 후 호스트·예약은 0이고 정리 미확인도 0이다. 호스트의 강제 종료 통계 1회는 의도한 장애 주입이다.
- Windows 중첩 Job의 원시 `activeProcesses` 값은 고유 PID 수와 같지 않으므로 합산해서 프로세스 누수로 판정하지 않았다. 직접 소유한 PID/시작 시각과 OS 그룹 회수를 함께 확인했다.

## 도구 검증

- 짧은 smoke 시험은 통과했지만 `qualifiedLongRun=false`로 기록한다.
- 별도 smoke 중단 시험은 종료 코드 2, `passed=false`, `qualifiedLongRun=false`, 강제 종료 없이 실행기와 예약 0을 확인했다.
- 잘못된 인자 9가지와 도움말을 검사했다. 잘못된 실행 시간/게임 수/반복 수, 중복 옵션, smoke와 장시간 옵션의 혼용은 빌드/게임 실행 전에 거절한다.
- 실제 시험용 별도 빌드는 경고/오류 0개다. Node 구문 검사와 변경 파일의 공백 검사도 통과했다. 일반 계정/맵/원문 데이터와 `.env`는 건드리지 않았다.
- 장시간 시험 종료 후 기존 C# 혼합 게임 회귀 39건도 통과했다. 독립 진행·timeout 후 동일 인스턴스 재사용·DLL 고정·실행 중 중지·엔진 장애·호스트 종료를 확인했다.

## 판정의 한계

이 시험은 로컬 Windows의 한 부하 조건이다. 실제 배포 사양의 동시 수용량, Linux cgroup/파일·네트워크 격리, 모든 허용 API의 안전성이나 정확히 500ms에 물리적으로 실행을 정지하는 보장은 별도로 판정해야 한다. C# 공개 지원과 GC 기본값은 비활성을 유지한다.
