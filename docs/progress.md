## 2026-10-11 — 계정 파일의 프로세스 간 저장 충돌 수정

Google OAuth 작업은 `2bed40b`로 먼저 커밋했다. 리뷰의 높음 1번인 별도 프로세스 간 계정 JSON 갱신 유실을 수정했다. 저장소 인스턴스 내부 큐에 더해 같은 호스트의 프로세스들이 공유하는 파일 잠금을 적용하고, 마이그레이션·읽기·수정·저장을 같은 잠금 안에서 처리한다. 고유 임시 파일, 교체 전 소유권 검사, 종료된 PID의 잠금 복구와 Windows 삭제 지연 재시도를 추가했다. 살아 있는 소유자의 잠금은 시간 기준으로 회수하지 않는다. 잠금 정책과 수동 복구 조건은 [저장 어댑터](storage-adapters.md)에 기록했다.

전체 자동 테스트 97개와 Google OAuth 브라우저 검증을 통과했다. 추가된 9개 검사는 실제 유지보수 CLI와 별도 프로세스의 동시 저장, 계정·알고리즘 파일·경기 기록 보존, 종료된 소유자의 동시 복구, 다른 호스트의 잠금 유지, 긴 작업의 잠금 유지, 실패한 쓰기의 정리, 잠금 해제 실패 후 저장 결과 보존, 동시 마이그레이션을 포함한다. 파일 잠금 재리뷰에서 새로운 높음 문제는 확인하지 못했다.

작업실 브라우저 원본 검증은 저장 코드 불러오기 단계에서 두 번 실패했다. 기존 UI는 모달을 먼저 연 뒤 비동기로 목록을 갱신하며, 갱신 시작 당시 선택값을 복원한다. 갱신이 끝나기 전에 다른 코드를 선택하면 선택값이 되돌아가 불러오기가 진행되지 않을 수 있다(중간). 잠금 추가로 읽기 대기가 생기며 이 경합이 드러났다. 목록 갱신 후 선택하도록 임시 검증 스크립트에 대기를 추가한 경우 전체 작업실 흐름이 통과했다. 제품 UI와 원본 검증 스크립트는 변경하지 않았다. 앞선 리뷰의 중간 3건인 이전 OAuth 콜백의 세션 덮어쓰기, 같은 이메일의 목업/Google 계정 관리자 선택, OAuth 대기 요청 수 제한의 서비스 거부 가능성도 이번 수정 범위에서 제외했다.

## 2026-10-11 — 맵 관리에 게임 옵션 통합

맵 복사·복제 이름 중복 검사를 추가했다. 기본 이름이 사용 중이면 숫자 접미사를 붙여 제안하고 직접 입력한 중복 이름은 저장하지 않는다. 서버의 직렬 쓰기 구간에서 최신 초안·게시 이름을 함께 검사해 동시 복사 중복도 차단한다. 이름은 공백·Unicode 정규화·대소문자 기준을 맞춰 비교한다. 관련 자동 테스트와 브라우저에서 중복 경고·이름 변경 후 복제·자동 접미사 제안을 검증했다. 관리 브라우저 테스트의 기준 맵도 운영 표시 순서에 영향을 받지 않도록 고정했다.

맵 관리에 기본 샘플 복사·최신 초안 복제와 이름 입력 모달을 추가했다. 새 ID·리비전 1의 비노출 초안을 생성하고 원본·게시 버전은 유지한다. 전체 목록의 ↑ ↓로 순서를 저장하며 샘플을 포함한 순서는 운영 등록 파일의 displayOrder에 보관한다. 신규 맵은 끝에 추가하고 사용자 목록은 노출된 게시 맵만 같은 순서로 표시한다. 복사 원본 리비전과 이전 전체 순서를 쓰기 구간에서 검사해 동시 변경을 거부한다. 브라우저에서 복사·복제·충돌 입력 유지·필터 시 순서 비활성·사용자 맵 선택 순서를 검증했다.

## 2026-10-04 — 관리자 페이지 1단계
