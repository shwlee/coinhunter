## 2026-09-27 — 첫 게스트 웹 경기

### 완료한 작업 단위

- 실행 환경 선정: Node.js 자식 프로세스 + QuickJS WASM. 호출별 500ms 중단과 동일 인스턴스 유지 검증.
- 기본 프로젝트: npm 실행·테스트 명령, 잠금 파일, CI 구성.
- 게임 엔진: 최대 4인 독립 턴, 방향·코인·점수·경기 종료, -1 현재 턴 패널티.
- 아이템: 신발·망치·x2·랜덤점프 기본 효과, 교체·횟수 차감·일괄 출현·배치 제외.
- 기믹: BlackMatter와 벽 파괴 옵션 분리, HurryUp과 아이템 독립 일정.
- 웹: 게스트 파일 업로드, 샘플 다운로드, 더미 선택, 맵, 점수판, 실행 출력, 종료 화면.
- 통신: 세션별 경기 접근, SSE 상태 전송, 새로고침 후 재연결, 종료 시 프로세스 정리.
- 문서: 실행 안내, 게임 규칙, API, 데이터·통신, 실행 검증 보고서.

### 검증

- `npm test`: 런타임·게임·서버 자동 테스트.
- `npm run verify:runtime`: 정상 → 500ms 무한 루프 중단 → 동일 PID·필드로 정상 복구.
- `npm run demo`: 4인 자동 경기에서 코인 소진으로 종료.
- `npm run test:browser`: 파일 업로드, 득점, 4인 표시, 재연결, 종료, 모바일 가로 넘침 없음, 시간 초과 후 복구 출력.
- 데스크톱·모바일 스크린샷을 실제로 확인. 생성 파일은 `artifacts/`이며 커밋에서 제외.
- 원격 CI는 구성만 추가했다. 실행 완료로 간주하지 않는다.
