# 로컬 알고리즘 작업실

## 실행

`npm ci` 후 `npm start`로 실행하고 `http://127.0.0.1:3000/editor`를 연다. 시작 전에 CodeMirror 정적 자원을 자동 빌드한다. 실행 중 CDN이나 Google에 접속하지 않는다.

목업 로그인에서 초기 관리자 또는 개발용 직원 계정을 선택한다. 최초 로그인 시 계정을 자동 생성하고, 계정 데이터와 알고리즘을 `data/accounts/store.json`에 저장한다. 파일은 Git에서 제외된다. 브라우저가 달라도 같은 목업 계정을 선택하면 같은 코드를 열 수 있다.

현재 로그인은 실제 Google 계정 소유를 증명하지 않는 로컬 개발 전용이다. HTTP 서버와 목업 로그인 모두 루프백 환경에 한정한다. `NODE_ENV=production`에서는 기본적으로 목업이 꺼지며 목업을 강제로 켜면 서버 생성이 실패한다. 실제 Google 인증은 배포 전에 구현·검증해야 한다.

## 설정

`.env.example`은 설정 참고 파일이다. 현재 서버는 `.env` 파일을 자동 로딩하지 않으므로 PowerShell 환경 변수로 지정한다.

```powershell
$env:AUTH_MODE = 'mock'
$env:INITIAL_ADMIN_EMAIL = 'vactormanbear@gmail.com'
$env:MOCK_COMPANY_DOMAIN = 'company.test'
npm start
```

- `AUTH_MODE`: `mock` 또는 `disabled`. 생략하면 개발에서는 mock, production에서는 disabled.
- `INITIAL_ADMIN_EMAIL`: 초기 관리자 이메일. 기본 `vactormanbear@gmail.com`. 관리자 계정은 회사 도메인 예외다.
- `MOCK_COMPANY_DOMAIN`: 개발용 직원 두 계정의 도메인. 기본 `company.test`. 실제 Workspace 허용 도메인을 검증하는 설정은 아니다.
- `ACCOUNTS_FILE`: 사용자·코드 저장 파일 경로. 상대 경로는 실행 디렉터리 기준.
- `PORT`: 기본 3000.

초기 관리자 설정은 해당 이메일이 처음 가입하고 관리자 기록이 아직 없을 때만 적용된다. 설정 변경으로 기존 관리자 권한을 자동 회수하거나 기존 일반 사용자를 승격하지 않는다. 이후 변경은 작업실의 사용자 관리에서 처리한다. 개발용 로그인 선택지는 초기 관리자·developer·tester 세 계정이다.

## 작성과 테스트

- AI로 작성 / 코드 편집 탭을 제공한다. 편집기는 CodeMirror의 구문 강조·줄 번호·들여쓰기·괄호 처리·undo/redo와 검색을 제공한다.
- 새 문서는 기존 길찾기 샘플로 시작한다. 파일 가져오기는 새 미저장 문서를 만든다.
- 저장은 현재 항목 갱신, 새 이름 저장은 별도 항목 생성이다. 문법 오류가 있는 작업 중 코드도 보관할 수 있지만 실행 전에는 검증한다.
- 다른 창의 저장과 충돌하면 409 오류를 표시하고 편집 내용을 보존한다. 별도 코드 히스토리나 자동 저장은 없다.
- 테스트 준비는 편집 코드를 같은 출처 게임 패널에 전달한다. 게임 설정과 시작은 게임 패널에서 진행한다. 이후 편집은 실행 코드에 영향을 주지 않는다.
- 이전 코드 대결은 게임 패널에서 파일 또는 본인 저장 코드를 불러와 선택한다. 저장 목록은 새로고침 버튼으로 갱신한다.
- 테스트는 기존 게임 화면·서버 엔진·SSE·실행 프로세스를 그대로 사용한다. iframe과 부모는 출처·송신 창을 검사하여 코드 사본과 준비/경기 상태만 교환한다. 별도 축소 엔진은 없다.
- 테스트 결과 분석과 `debug.print` 출력은 게임 패널에 표시된다. 코드·선택한 게임 설정은 편집 화면을 유지하는 동안 보존된다.
- 좁은 화면에서는 작성/테스트 화면을 전환한다. 새로고침·이탈 시 미저장 코드 또는 실행 중 테스트가 있으면 브라우저 경고를 제공한다. 이탈만으로 경기를 종료하지 않으며 기존 재연결 정책을 유지한다. 명시적 중단·로그아웃·이용 중지에서는 경기를 종료한다.

## AI 범위

AI 영역은 개발용 목업이다. 요청문을 해석하거나 외부 AI로 전송하지 않고 고정된 길찾기 샘플만 반환한다. 결과 적용은 명시적 버튼으로 수행하며 편집기의 한 번의 undo로 되돌릴 수 있다. 요청 후 편집이 변경되면 덮어쓰기를 확인한다. 취소한 요청의 늦은 결과는 무시한다.

실제 AI 제공자·중계·비밀키·네트워크 경로가 정해지지 않았으므로 자연어 생성·수정 완료로 간주하지 않는다.

## 계정·관리·저장

- 세션은 서버 메모리의 임의 토큰과 HttpOnly/SameSite 쿠키로 연결하며 유효 기간은 8시간이다. 서버 재시작 시 재로그인한다.
- 계정별 코드 조회·변경·저장된 코드 경기 실행을 검사한다. 로그인 사용자는 계정 단위로 동시 경기 한도를 적용한다.
- 관리자는 사용자 이용 중지/허용과 역할 변경을 수행한다. 마지막 활성 관리자는 해제할 수 없다.
- 이용 중지 시 해당 계정의 모든 세션을 폐기하고 경기를 중단하며 열린 SSE 연결을 닫는다. 해제 후 새 로그인이 필요하다.
- 로그아웃은 현재 세션을 폐기하고 해당 계정의 진행 중 경기를 종료한다.
- 파일 저장은 단일 서버 프로세스의 직렬 갱신·임시 파일 교체를 사용한다. 저장소를 여러 서버 프로세스가 동시에 공유하는 운영은 지원하지 않는다. 운영 배포 전에 DB 이전 여부를 결정한다.
- 백업은 서버를 종료한 후 저장 파일을 복사한다. 복원도 서버 종료 상태에서 같은 경로에 배치한다. 유실된 관리자 복구가 필요하면 데이터 파일을 먼저 백업하고 오프라인 관리 절차로 처리한다.

## 검증

`npm test`: 기존 엔진과 함께 계정별 접근, 저장 충돌, 재로그인·파일 재로드 후 데이터 유지, 계정 단위 경기 한도, 이용 중지·세션 폐기, 마지막 관리자 보호를 검사한다.

`npm run test:authoring`: 목업 로그인→편집·저장→목업 생성 적용/undo→테스트 경기→결과 분석, 작은 화면, 별도 브라우저 세션의 저장 목록을 검사한다.

`npm run test:browser`: 기존 게스트 플레이·이전 코드 대결 회귀 검사. 스크린샷은 `artifacts/`에 생성한다.

## 배포 전 남은 작업

실제 Google OIDC와 사용자 식별자 `sub` 연결, 회사 Workspace 제한과 관리자 예외 검증, OAuth 클라이언트·콜백·HTTPS·프록시 설정, 실제 AI 생성/수정 어댑터, 운영 DB·세션 저장소·백업 정책을 완료해야 한다. 목업 이메일을 실제 Google 신원으로 자동 신뢰하여 계정을 합치지 않는다.
