# 첫 웹 구현의 게임 규칙과 결정

- 기준일: 2026-09-27
- 사용자 확정 요구는 implementation-plan.md를 따른다. 아래 세부 선택은 구현을 진행하기 위한 초기값이며 제품 기획의 새 확정 사항으로 간주하지 않는다.

## 적용한 세부 선택

| 항목 | 첫 구현의 선택 |
| --- | --- |
| 기본 액션 시간 | 300ms |
| 신발 중 모든 액션 | 150ms, 알고리즘 계산 시간은 별도 |
| 상태 확정 | 액션 종료 시 위치·획득·벽 파괴를 반영 |
| 동일 서버 처리 회차의 동시 완료 | 플레이어 번호 순으로 확정; 향후 대회 공정성 규칙은 별도 |
| 플레이어 충돌 | 서로의 이동을 막지 않음 |
| 배치 제외 기준 | 이동 중에는 출발 칸을 현재 확정 위치로 사용 |
| 효과 차감 | 액션 시작 시 적용된 효과에만 차감. 새 효과에는 이전 턴 차감 없음 |
| 점프 실패 | 한 턴 소모, 남은 횟수가 있으면 다음 턴에 다시 시도 |
| timeout 상태 | 중단 이전의 사용자 인스턴스 필드는 유지 |
| 연결 끊김 | 경기는 계속 진행. 같은 게스트 세션으로 재연결 가능 |
| 실행 프로세스 자체 장애 | 전체 경기 종료, 자동 재시작 없음 |

서버는 20ms 간격으로 완료 액션과 기믹을 검사한다. 목표 액션 길이와 실제 처리 시점 사이에 스케줄러 오차가 발생할 수 있다. 알고리즘 요청은 자식 프로세스에서 병행하며 공통 턴을 기다리지 않는다.

## 기존 규칙

- 코인 점수 10/30/100/200/500.
- 기본 한 칸 이동, 맵 외부는 파괴할 수 없는 경계다.
- 첫 샘플 맵은 12×10이며 네 모서리가 시작점이다.
- -1·오류·시간 초과는 현재 턴만 제자리 패널티다.
- 벽 방향 이동은 물음표·고개 갸웃 액션이다.
- 모든 코인이 사라지면 경기 종료. 아이템 잔존은 종료를 막지 않는다.
- 120초 경과 시 HurryUp: 낮은 점수 코인부터 제거한다. 종류별 제거 간격은 300/700/1000/1300/1300ms다.

## 아이템

- 신발: 획득 다음 턴부터 기본 3턴 동안 액션 시간 절반. 실패 턴 포함.
- 망치: 내부 벽을 기본 3개 파괴할 때까지 유지. 파괴는 이동 대신 수행하고 그 턴에는 진입하지 않는다. 경계 또는 다른 플레이어가 이미 파괴한 벽은 횟수를 차감하지 않는다.
- x2: 다음 3개 실제 획득 코인에 두 배 점수.
- 랜덤점프: 사용자 알고리즘을 호출하지 않고 3턴 동안 유효한 빈칸으로 순간이동. 목적지가 없으면 주사위 파괴·고개 갸웃, 횟수 차감.
- 새 아이템을 얻으면 기존 효과를 없애고 새 기본 횟수로 교체한다. 동일 종류도 동일 처리한다.

## 생성

샘플 맵은 첫 아이템 생성 5초, 이후 검사 간격 15초로 설정되어 있다. 관리자 UI는 후속 단계이며 현재 값은 서버의 맵 설정에서만 변경할 수 있다.

- 네 종류를 하나씩 일괄 생성한다. 기존 아이템이 남아 있으면 생성하지 않는다.
- 네 칸이 확보되지 않으면 해당 회차를 건너뛰고 다음 설정 시점에 검사한다.
- 빈칸은 코인·벽·기존 아이템이 없는 칸이다. 모든 플레이어의 현재 칸과 상하좌우 직선 두 칸을 제외한다. 벽 너머라도 좌표상 두 칸 범위는 제외한다.
- 랜덤점프 목적지도 같은 규칙을 사용한다.
- 아이템은 HurryUp 중에도 생성할 수 있다. 종료된 경기에는 생성하지 않는다.
- BlackMatter는 켠 경우 일반 진행 중 15초마다 최대 4개 생성한다. HurryUp에서는 추가 생성하지 않는다.
- 벽 파괴는 켠 경우 3초마다 내부 벽 하나를 제거하며 HurryUp에도 진행한다.

## 후속 보완

맵 편집·랜덤 맵 생성·import/export, 관리자 옵션 UI, 추가 맵, 연출 정교화는 아직 완료되지 않았다. 현재 캐릭터와 이펙트는 외부 자산 없이 Canvas로 구현한 개발용 표현이다.
