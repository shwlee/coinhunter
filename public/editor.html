    현재는 선택한 템플릿과 가중치로 코드를 생성합니다. 자유 입력은 실제 AI 생성 연결 전까지 코드에 반영되지 않습니다. 

    
                    
                  
    
                
    
              
    
            
    
            
    
              알고리즘 작성 규칙
              
    
                module.exports로 클래스를 내보내세요. initialize(myNumber, column, row), getName(),
                moveNext(map, myPosition, items)를 구현합니다.
              
    
              
    
                방향: 0 왼쪽 · 1 위 · 2 오른쪽 · 3 아래 · -1 제자리. 벽 -1, 빈칸 0, 코인
                10/30/100/200/500. items는 신발·망치·x2·점프의 위치이며 없으면 -1입니다.
              
    
              
    
                debug.print로 출력할 수 있습니다. 각 호출 제한은 500ms이며 비동기·import·static·외부
                파일/네트워크 접근은 지원하지 않습니다. 현재 위치는 myPosition을 사용하세요. 점프
                효과 중에는 알고리즘이 호출되지 않습니다.
              
    
            
    
          
    
          
    
            
    
              
              
    
                맵과 시작 위치만 선택해 혼자 테스트합니다. 캐릭터는 실행할 때마다 무작위로
                배정됩니다.

            API 키 발급 안내 ↗
          
      
          
      
            게임 로그인과 AI API 인증은 별개입니다. 제공자의 API 키를 사용하세요. API 이용료는 해당
            제공자 계정에 적용됩니다.
          
      
          
      
            
            
      
              
              
      
            
      
            
            
      
              키는 서버로 전달됩니다. 임시 키는 로그아웃·세션 만료·서버 재시작 시 제거됩니다. 이후
              AI 생성에서는 요청과 코드가 선택한 제공자로 전송됩니다.
