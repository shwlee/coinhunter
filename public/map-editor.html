배치 도구

도구 선택 후 바닥을 클릭하세요. 네 모서리는 시작 칸으로 비워 둡니다.

게임판을 먼저 생성하세요.

열과 행을 입력하면 빈 게임판이 만들어집니다.

저장한 맵은 초안이며 사용자에게 자동 노출되지 않습니다.

int[] 맵 가져오기

왼쪽 위부터 행 순서로 입력합니다. -1: 벽, 0: 빈칸, 10·30·100·200·500: 코인.

파일을 선택하거나 배열을 붙여 넣으세요. 파일은 64 KiB 이하이며 코드 주석·수식은 지원하지 않습니다.

기본 게임 옵션을 가진 새 미저장 맵으로 가져옵니다. 이름·옵션은 가져온 뒤 변경할 수 있으며 저장·게시는 별도로 진행합니다.

int[] 맵 내보내기

현재 배치만 내보냅니다. 이름·게임 옵션·게시 상태를 함께 보관하려면 JSON 내보내기를 사용하세요.

대칭 랜덤 맵 생성

네 시작 칸을 비우고 모든 이동 가능 공간을 연결합니다. 생성 후 직접 편집할 수 있습니다.

템플릿 선택 후 밀도와 점수를 직접 조정할 수 있습니다. 혼합에는 블랙매터를 넣지 않습니다.

벽 밀도는 시작 칸을 제외한 전체 공간, 코인 밀도는 벽과 시작 칸을 제외한 공간 기준입니다. 대칭·통로 보호로 실제 밀도는 달라질 수 있습니다.

새 맵으로 생성하며 경기 옵션은 기본값을 사용합니다. 저장·게시는 별도로 진행합니다.

맵 저장

저장 방식

배치와 경기 옵션을 함께 초안으로 저장합니다. 게시·노출은 맵 관리에서 변경합니다.

맵 게시

대칭·시작 칸·코인·통로 연결을 검사합니다. 진행 중인 경기는 기존 맵을 유지합니다.
