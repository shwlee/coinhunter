C# 작성 규약

기본 타입 int·long·double·bool·char·string과 1차원 배열, int 기반 Queue·List·HashSet·Dictionary·PriorityQueue를 지원합니다. 컬렉션은 승인된 생성·추가·조회·삭제 메서드만 허용하며 LINQ·Sort·사용자 comparer는 지원하지 않습니다. Dictionary의 새 키 추가에는 Add를 사용하세요.

Math는 Abs·Min·Max·Clamp·Sqrt·Pow·Floor·Ceiling의 승인된 overload를 지원합니다. 단일 배열은 최대 1,048,576요소, 컬렉션 Count/요청 용량은 65,536, 문자열은 65,536자로 제한됩니다. 현재 C# 베타 이동 호출에는 누적 관리 할당 32MiB 한도도 적용됩니다.

전역 public class Player 하나에 Initialize(int,int,int), GetName(), MoveNext(int[],int,int[])를 public 인스턴스 메서드로 작성하세요. 반환 방향은 0=왼쪽, 1=위, 2=오른쪽, 3=아래, -1=제자리입니다.

map은 1차원 int[]이며 -1은 벽, 0은 빈칸, 양수는 코인 점수입니다. myPosition은 현재 칸 인덱스이며 좌표는 열=myPosition%column, 행=myPosition/column입니다. items는 신발·망치·x2·랜덤점프 순서의 위치 int[4]이며 없으면 -1입니다. Debug.Print(값)으로 출력합니다.

단일 파일·동기 코드와 승인된 기본 API만 사용하세요. 외부 라이브러리, 사용자 static 선언, 재귀, goto, try/catch/finally, 비동기·스레드·Task, sleep, 파일·네트워크·리플렉션을 허용하지 않습니다. 명시적 생성자·추가 클래스·상속·LINQ·lambda도 지원하지 않습니다.

각 호출의 알고리즘 제한은 500ms이며 timeout은 해당 턴의 제자리 패널티입니다. 승인 API도 크기/연산 한도가 있습니다. 검사는 모든 입력의 종료를 증명하지 않습니다. 프롬프트 생성은 현재 JavaScript용입니다.

    대화 방식

    새 대화·다른 AI에서는 전체 규약을 전달합니다.

    사용하는 AI에 프롬프트를 전달하고, 받은 JavaScript 코드는 편집기에 붙여 넣어 코드 검사·테스트를 진행하세요. 프롬프트 복사는 API 키나 API 사용료가 필요하지 않습니다.

    본문이 깁니다. 사용하는 AI의 입력 한도를 확인하세요. 코드를 자동으로 줄이거나 생략하지 않았습니다.

    알고리즘 작성 규칙

    module.exports로 클래스를 내보내세요. initialize(myNumber, column, row), getName(), moveNext(map, myPosition, items)를 구현합니다.

    방향: 0 왼쪽 · 1 위 · 2 오른쪽 · 3 아래 · -1 제자리. 벽 -1, 빈칸 0, 코인 10/30/100/200/500. items는 신발·망치·x2·점프의 위치이며 없으면 -1입니다.

    debug.print로 출력할 수 있습니다. 각 호출 제한은 500ms이며 비동기·import·static·외부 파일/네트워크 접근은 지원하지 않습니다. 현재 위치는 myPosition을 사용하세요. 점프 효과 중에는 알고리즘이 호출되지 않습니다.

    맵과 시작 위치만 선택해 혼자 테스트합니다. 캐릭터는 실행할 때마다 무작위로 배정됩니다.
